
# 🔓 Actividad exploratoria: Recuperación de Señales Secretas (Reverse)

### 📌 Propósito

Explorar el funcionamiento del proceso de **Reverse**, mediante la recuperación de diferentes señales de audio secretas a partir de una misma señal objetivo (*target*) y las claves generadas previamente mediante **Imitation**.

La actividad busca observar cómo una misma señal de audio, combinada con diferentes claves, permite recuperar distintos mensajes secretos.

### 📂 Archivos suministrados

Para el desarrollo de la actividad se proporcionan:

- 🎵 **audio.wav:** señal de audio objetivo (*target*).
- 🔑 **key1.csv, key2.csv, key3.csv, key4.csv y key5.csv:** cinco claves generadas mediante Imitation.
- 💻 **Reverse_GitHub.ipynb:** código Python que implementa el proceso Reverse.

### 🧪 Parte 1. Ejecución de Reverse

Ejecuta el código de Reverse utilizando `audio.wav` como señal objetivo y, de manera independiente, cada una de las cinco claves.

Como resultado, debes obtener cinco señales de audio recuperadas, correspondientes a los cinco mensajes secretos.

### 🎧 Parte 2. Exploración de los resultados

1. Reproduce y escucha las cinco señales de audio recuperadas.
2. Observa cómo una misma señal objetivo permite recuperar diferentes mensajes secretos dependiendo de la clave utilizada.

**📌 Nota:** Esta actividad es exploratoria y no hace parte de la evaluación de la asignatura.
